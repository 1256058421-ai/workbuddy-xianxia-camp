05
>WHAT TO PICK

去网上收集，先想清楚要什么。

选题

别人最近在讲什么、搜什么。选题清楚了，后面才好做内容。

同行

对方主页、视频号。看他们怎么讲，用来对照，不是照搬。

政策口径

政府网、官方文件。讲课、获客，口径要对，不能讲错。

用户原话

评论区、问答里的原句。比自己想出来的更真实。

行业数字

公开报告、协会数据。有数字，内容才站得住。

招标 / 采购

对接企业客户的，政府官网里就有。要说清是哪一类。

PPT、公众号、短视频、宝妈内容，收集的内容可以不同，步骤是一样的。

08
>STEP 01 · SOURCE

第 1 步：先确认去哪找。

1
先定行业，再定网站

你要给它源头：网址、网站名。没有源头，它不知道该去哪找，找回来也不好核对。

源头是你选的，不是它选的

政府官网

招标、政策、通知。公开、能核对。对接企业客户的，优先看这里。

行业协会 / 官网

行业报告、标准、公开数据。比随便一篇文章更靠得住。

同行主页

对方官网、视频号主页。看他们怎么讲，用来对照。

评论和问答

真实用户原话。选题、需求从这里来，不是自己想出来的。

一次给 2～4 个网站就够。给太多，反而搜不准。

>STEP 02 · QUERY

第 2 步：说清搜哪一类。

说得太宽

帮我找获客素材
好的，招标有很多种……获客素材也很多……
政府官网里招标很多。你不说哪一类，找回来也不好用。
类别没说清 · 结果会很散
>
够清楚能搜
只搜 2026 年、本市、信息化 / 软件类招标，只要公开公告
一类，比「所有招标」有用
  • 时间：今年 / 近 90 天
  • 地点：哪座城市、哪个区
  • 类别：信息化、培训、设备……
  • 只要公开信息，需要登录才能看的先不要
同学的需求也是这样：先听清要哪一类，再去官网上看
11
>BOUNDARIES

搜索要划四条线。范围清楚，找回来才能用。

看日期

网上的信息会过期。政策、招标、热点，都要写「只要最近××」。

看公开

只要不用登录就能看的。需要付费、需要登录的，先不要收集。

看出处

每条都要带来源链接。没有链接的，先不要写进正文。

看版权

公开信息可以整理成你的文件。原文不要整篇拿去发布。

> 边界可以跟在指令后面

只收集公开可访问的内容；每条必须带来源链接和发布日期；过期或没有链接的标出来，不要写进正文。

>STEP 04 · OUTPUT

第 4 步：按清单，输出你要的文件。

4
格式可以换，步骤不能跳

Word、HTML、PDF、PPT，公众号文章、视频脚本，都一样：有清单才能写。没有清单，写出来对不上来源。

先说格式，再说篇幅和给谁看

行业报告

给自己看、给客户看。把清单收成一份能翻的文件。

PPT / 网页

要讲课、要投影，就出 HTML 或 PPT。就像我们现在这套课件。

公众号 / 视频稿

获客用的。素材从清单来，观点你来定。短视频明天再教。

表格也行

招标清单、同行对照，用表格往往比长文更清楚。

>你开口指定格式就行
Word HTML PDF PPT Excel 公众号 视频脚本

>WHY THE LIBRARY

知识库是积出来的。不是一次建完的。

+
每一次收集回来，都要存回知识库

只用内部资料，容易只剩自己那一套。只用外部资料，又少了你自己的内容。两样放进同一个库里，才会越用越有用。

每一次收集回来，都往库里加一层

今天这一层

网上收集的招标、选题、口径，进了「外部资料」文件夹。

明天还能加

短视频素材、评论原话、新的政策，继续往同一个库里放。

提问范围变大

以后问「我们行业最近有什么」，它能答到你亲自收集回来的东西。

换电脑还在

资料在云端：人换地方，库还跟着你。
